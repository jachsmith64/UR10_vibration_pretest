# UR10 末端 Y 向抗振仿真（冻结等效扰动 + SFC）—— V1.2

> 审查对象：本文件描述的就是本轮**实际执行**的代码。批量实验的全部原始数据在
> `SFC_sim_V1_2_DATA.zip`。本包（`SFC_sim_V1_2_CODE.zip`）不含任何运行结果、图片、缓存。

本工程只研究一件事：

> 冻结等效扰动力 `Fd(t)` 作用于 UR10 末端 TCP 的 Y 方向时，
> SFC 本身能否降低末端 Y 向振动；非线性剪切增稠项相比普通线性阻抗是否有额外贡献。

**V1.2 的唯一核心变化在数据入口。** 主架构、TCP 施力方式、冻结扰动、A0/Alinear/ASFC
三组对照全部保留，没有推倒重写。

## 本轮版本说明（V1.2）

### 唯一核心任务

预实验原始横向误差里混了两样东西：

```
e_raw(t) = b(t) + e_vib(t)
   b(t)     : 方向性 / 准静态慢偏移（正向稳态偏 +，反向稳态偏 −，幅值几十 µm）
   e_vib(t) : 真正要研究的快速振动
```

V1.1 直接对 `e_raw` 做重建，于是重建出来的 `Fd` 里有一大半力气花在复现那个慢偏移上，
A0 的响应也就整体坐在一边，SFC 的作用被慢偏移掩盖了。V1.2 的做法是：

> **先构造「理想已知的慢偏移基线」`b(t)` 并从 `e_raw` 里扣掉，得到相对干净的净振动
> `e_vib`；之后基于 `e_vib` 重新做扰动重建、重新跑 A0/Alinear/ASFC，并重新输出对比。**

这是一次**理想机制验证**：假设 `b(t)` 可以被完全正确地离线知道（允许全序列、允许未来帧、
允许全局平滑），只检验 SFC 在这份净振动上的控制效果。
**132 Hz 在线估计、实时预测、真实部署都不在本轮范围内**，那是下一阶段的问题。

### 沿用 V1.1 的两处修正

**修正 1：Fd 作用于真正的 TCP 点。**
`mujoco.mj_applyFT(model, data, force=[0,Fd,0], torque=0, point=TCP site 世界坐标,
body=wrist_3_link, qfrc_target)`。数值验证：与 `J_tcp^T·[0,F,0]` 逐元素一致，
`max_abs_err = 0.000e+00`（参考量级 6.910e-01）。V1.0 的「作用在刚体质心」写法在关节 1 上
差 0.691 N·m。

**修正 2：n 与 μ 是两个显式独立参数。**
删掉了旧的 `n = 1 + ln(5)/ln(5)` 式伪推导。`n` 直接配置（`SFC_N_DEFAULT`），`μ` 由
「参考速度 `v_ref` 处的相对阻尼强度 `r`」标定：`μ = r·B0 / v_ref^(n−1)`。

## 一、慢偏移 b(t) 是怎么构造的（§三）

### 为什么不能用「全程单一低通」

启动 / 转向 / 停止段存在 **±125 µm** 的巨大瞬态尖峰。全程单一低通会把这些尖峰一起吸进
`b(t)`，等于把本该保留的振动错误地削弱掉。所以按**运动阶段**分别处理：

```
pre_motion → start → fwd_steady → turn → ret_steady → stop
```

分段边界直接复用 `disturbance.detect_cuts` 的 `iA/iB/iC/iD`，不另立一套切窗规则。
实测切点（1 ms 网格，共 7756 点）：

| 段 | 索引区间 | 说明 |
|---|---|---|
| `start` | [0, 1925] | 静止 → 正向稳态 |
| `fwd_steady` | [1926, 3461] | 正向稳态，x ∈ [3.202, 11.005] mm |
| `turn` | [3462, 4523] | 换向（实际速度反向点在 t≈3.862 s） |
| `ret_steady` | [4524, 6573] | 反向稳态，x ∈ [0.173, 10.667] mm |
| `stop` | [6574, 7755] | 反向稳态 → 静止 |

### 稳态段：方向相关的 b±(x)

**不是**取一个常数均值，而是沿程分箱：

1. 按 `nominal_along_mm` 分箱，箱宽 **1.0 mm**，箱内样本数 < 8 则弃用该箱；
2. **每箱取中位数**（不用均值，避免被振动尖峰拉动）；
3. 对离散点 `(x_i, b_i)` 做 **LOWESS** 鲁棒平滑（局部线性 + 三次权核 + 双平方鲁棒迭代 3 轮），
   带宽 **2.5 mm**，得到连续、光滑、稳健的慢中心线 `b+(x)` / `b−(x)`。
   查询点一律**夹紧到拟合区间内**——LOWESS 是局部回归，外推会沿边缘斜率线性飞出去。

**分箱宽度是量出来的，不是拍的。** 实测正向稳态段谱能量：

| 频带 | 占比 | 对应波长 |
|---|---|---|
| 0–1 Hz（慢漂移） | 33.7% | ~7.7 mm |
| 2.5–10 Hz（振动簇） | 53.5% | 0.70–1.28 mm |

若 `bin` 取得比振动波长还小（曾用 0.5 mm），箱内不足一个振动周期，中位数会被振动相位
拉动，出现 ±20 µm 的假慢偏移。候选参数实测对比：

| bin / span | 慢带残留 | 振动带残留 |
|---|---|---|
| **1.0 / 2.5 mm** | **36–40%** | **99.9%** ← 选用 |
| 1.0 / 3.0 mm | 36–46% | 100.1% |
| 1.5 / 3.0 mm | 35–43% | 100.3% |
| 2.0 / 3.0 mm | 43–44% | 98.7–100.0% |

### 过渡段：三次 Hermite 桥接 + 单调限幅

```
start : 静止基线 b_rest(≈0)  →  b+(x_iA)
turn  : b+(x_iB)             →  b−(x_iC)
stop  : b−(x_iD)             →  静止基线 b_rest
```

一阶连续（C1）：端点斜率由相邻稳态段的 `db/dx · dx/dt` 给出。

**但斜率必须做单调限幅（Fritsch–Carlson）。** 理由：正向稳态段在行程末端正处于减速段，
`b+(x)` 在那儿被减速瞬态污染而陡升，继承来的 `m0 = db+/dx · dx/dt` 是**正的**——方向与
「转向段必须下降」相反。不加限制的三次 Hermite 会先往上冲到 +53 µm 再往下走，白白在转向段
留下约 45 µm 的**虚假正偏置**（实测该段 `e_vib` 中位数被拉到 −39 µm，而原始数据该段中位数
只有 +6.5 µm，说明这 45 µm 是 `b` 自己造的，不是数据里的）。

限幅判据（`Δ = p1−p0`，`α = m0·span/Δ`，`β = m1·span/Δ`）：
三次 Hermite 单调 ⟺ `α,β ≥ 0` 且 `α²+β² ≤ 9`。越界就投影回该区域。
加上限幅后 `b` 的范围从 −33.13~**53.60** 收回到 −33.13~**39.63** µm，转向段中位数从
−39.47 改善到 **−32.21** µm，且**振动带一个点都没少吃**。

### 结果

| 段 | e_raw 中位数 | e_vib 中位数 | 振动带保留 | 慢带保留 | ptp 保留 |
|---|---|---|---|---|---|
| start | 1.02 | −6.86 | 100.5% | 93.3% | 127.7 |
| **fwd_steady** | **+24.15** | **−0.75** | **99.9%** | 48.6% | 66.9 |
| turn | 6.48 | −32.21 | 101.1% | 81.5% | 149.0 |
| **ret_steady** | **−18.96** | **−1.07** | **99.9%** | 55.2% | 75.4 |
| stop | 3.15 | 5.80 | 100.3% | 77.8% | 38.3 |

整体：`e_raw` rms **35.53 µm → e_vib rms 26.78 µm**。

**两个稳态段的中位数从 +24.15 / −18.96 µm 压到 −0.75 / −1.07 µm**，
而**振动带在全部五段都保留了 99.9–101.1%** —— `b` 拿掉的是慢偏移，不是振动。
转向段的 −32.21 µm 中位数来自原始数据本身的剧烈不对称瞬态（该段 ptp 达 176 µm，
正侧只到 +75 而负侧到 −125），不是 `b` 的缺陷。

### §五 机器可判验收（13 项全部通过，实现在 `slowoffset.acceptance`）

1. 两个稳态段 `e_vib` 中位数接近 0（绝对 2.0 µm 与相对 0.15·rms 双重口径）；
2. 两个稳态段扣除后比原始更居中；
3. 三个过渡段的巨幅瞬态被保留。判据用的是**数学硬下界**而非拍的峰值比例：
   由 `max(e−b) ≥ max(e) − max(b)`、`min(e−b) ≤ min(e) − min(b)` 相减得
   **`ptp(e_vib) ≥ ptp(e_raw) − ptp(b)`**，即「`b` 至多吃掉自己那么大的峰谷」。
   这是恒成立的等式约束，不含任何主观容差，违反即说明 `b` 的构造不自洽；
4. 两个稳态段的**振动带能量守恒**（≥90%，实测 99.9%）；
5. 整体 RMS 下降；
6. 三个过渡段的 `b` 变化幅度受控（相对该段必须走完的 `|Δb|`，而非相对瞬态幅值）。

验收在**第一次尝试即通过**，没有触发放宽平滑带宽的回退。

## 二、扰动重建（§六/§七）

输入从 `e_raw` 换成 `e_vib`，框架不变：
`净振动 → 测 G(f) → 带限反演 → 基线回放 → 残差迭代 → 冻结 Fd`。

### 为什么必须把反演带宽从 11/16 Hz 拓宽到 30/45 Hz

V1.1 的 11/16 Hz 是针对 `e_raw`（慢漂移占主导）定的。目标换成 `e_vib` 后，实测其谱能量分布为：

| 频带 | rms | 说明 |
|---|---|---|
| 0–2.5 Hz | 8.82 µm | |
| 2.5–5 Hz | 8.81 µm | |
| 5–11 Hz | 5.70 µm | |
| 11–16 Hz | 3.40 µm | 渐减带 |
| **16–45 Hz** | **3.14 µm** | **约占目标总能量 20%** ← 旧带宽整体切掉 |

且 16–45 Hz 段**不是插值噪声**：谱形在 24–30 Hz 有明确凹陷、在 34–36 Hz 有明显共振峰；
原始记录中位采样间隔 7.56 ms（≈132 Hz），Nyquist ≈ 66 Hz，35 Hz 远在其下，是真实振动。

按 11/16 Hz 反演时，逐带复现率实测：0–2.5 Hz 97.8%、2.5–5 Hz 98.7%、5–11 Hz 98.6%，
而 **16–45 Hz 只有 1.8%**——残差 3.453 µm 里有 3.135 µm 全部来自这一段，
残差被硬性钉在 21.7%，**20% 的验收门槛在结构上无法达到**。

拓宽后（`PROBE_FMAX_HZ` 同步从 35 → 50 Hz，否则 `plant.at()` 会在 35 Hz 处被
`np.interp` 夹住，等于拿一个错的增益去反演高频段）：

| | V1.1（e_raw，11/16 Hz） | 中间态（e_vib，11/16 Hz） | **V1.2（e_vib，30/45 Hz）** |
|---|---|---|---|
| 目标 rms | 28.62 µm | 15.95 µm | **15.61 µm** |
| 复现 e_sim rms | 25.77 µm | 15.30 µm | **14.18 µm** |
| corr | 0.9874 | 0.9764 ✗ | **0.9918 ✓** |
| 残差 rms | 5.27 µm | 3.45 µm | **2.62 µm** |
| 残差/目标 | 18.4% ✓ | 21.7% ✗ | **16.8% ✓** |
| 收敛迭代数 | 5 | 5（未收敛） | **2（提前收敛）** |

冻结：`Fd` rms **0.935 N**，峰值 4.574 N，`sha256 = 4deee98bf889…`

## 三、三组对照结果（§八/§九）

本轮不做几十组全扫描，只跑有代表性的几组：

| 组 | 模式 | 总 RMS (µm) | 振动带 RMS (µm) | 相对 A0 | 相对 Alinear |
|---|---|---|---|---|---|
| A0 | F = 0 | 14.180 | 10.799 | — | — |
| Alinear | −Ke − B0v | 10.653 | 8.236 | +24.87% | — |
| 默认 ASFC | n=3.0, r=1.0 | 9.839 | 6.876 | +30.62% | **+7.64%**（振动带 +16.51%） |
| 中等 ASFC | n=2.0, r=2.0 | 9.048 | — | +36.19% | +15.07% |
| 强代表 ASFC | n=1.5, r=4.0 | **7.836** | — | **+44.74%** | **+26.45%** |

### 去慢偏移后，ASFC 与 Alinear 的差异变得清晰得多

同样这几组参数在 V1.1（`e_raw` 口径）下的表现：

| | V1.1（e_raw） | **V1.2（e_vib）** |
|---|---|---|
| 默认 ASFC 相对 Alinear | +0.50% | **+7.64%** |
| 默认 ASFC 相对 Alinear（振动带） | +13.2% | **+16.51%** |
| 强代表 (n=1.5, r=4) 相对 Alinear | +6.45% | **+26.45%** |

慢偏移被扣掉之后，同样的控制律表现出来的差异放大了 **4–15 倍**。
这说明 V1.1 里「SFC 相对线性阻抗几乎没有额外收益」的观感，
很大程度上是被慢偏移掩盖掉的，而不是控制律本身没有非线性效应。

### §9.2「回正阻碍」局部复查（沿程 2.5 ± 1.5 mm）

上一轮肉眼觉得「约 X≈2.5 mm 处 ASFC 妨碍回正」。本轮在该窗口内逐项检查
`e_vib / v / F_spring / F_linear_damping / F_shear / F_SFC`：

| 模式 | 窗口内 RMS (µm) |
|---|---|
| A0 | 34.20 |
| Alinear | 23.53 |
| ASFC | **18.89** |

**结论：去慢偏移后，原先怀疑的「ASFC 妨碍回正」不再成立**——该窗口内 ASFC 比 Alinear
还低 **+19.69%**。机理在图 `figR1` 里看得很清楚：`F_spring` 在该窗口只有 ±0.1 N 量级，
主导项是 `F_shear`，它在 x≈2.75 mm 处（速度最大处）峰值达 ~3.1 N，
正好把最大的那次负向偏移削掉。阻尼项在回正相内确实与速度反向（对回正方向不利），
但它同时抑制了反向过冲；两件事是同一枚硬币的两面，窗口 RMS 才是判据，实测窗口 RMS 更小。

## 五、当前实际控制链（三条支路严格独立）

```
① 扰动支路   Fd(t) ──mj_applyFT(作用点 = TCP site)──▶ UR10
```

## 八、关键口径

* **μ 的标定**：`v_ref = percentile(|v_A0|, 75%)`（去掉首尾各 3 s 瞬态），
  `μ = r·B0 / v_ref^(n−1)`，`r=1` 表示「在 `v_ref` 处剪切阻尼与线性阻尼等强」。
  本轮 `v_ref = 6.6243e-04 m/s`。
* **PSD / 频带一律用 `f_s = 1/median(Δt)` 从时间戳反推，不接受外部传入值。**
  时序 CSV 按 `TRACE_STRIDE=5` 抽稀落盘（1000 Hz → 200 Hz）；任何对 CSV 的频域分析
  若沿用物理步长 1000 Hz，频率轴会整体错位 5 倍，慢带 / 振动带的带内积分全错。
* **统计口径与落盘口径对齐**：`sweep_summary.csv` 与 `compare/summary.json` 的指标
  一律在抽稀后的序列上计算，保证两处数字逐位一致。
* **不施加任何力限幅**，`clip_applied` 恒为 `False`；用 `F_SFC_peak / τ 范数 /
  越限样本比例`作为等价安全指标。
* `SLOW_BAND_HZ = (0, 2.5)`，`VIB_BAND_HZ = (2.5, 45)`。

## 十、已知问题 / 遗留

1. **慢偏移在转向段的归属本质上是不确定的。** 换向时速度反向，`b` 既不是 `x` 的纯函数，
   也不是常值；本轮的单调 Hermite 桥接给出的是「合理」而非「唯一正确」的过渡。
   转向段 `e_vib` 中位数 −32.21 µm 主要来自原始数据本身的剧烈不对称瞬态。
2. **`b(t)` 用的是全局信息、允许看未来帧**，是理想化假设，不代表可实现方案。
   在线估计 / 实时预测不在本轮范围。
3. **Plant 仍是单构型标定**（`INIT_Q`）。沿程 DC 柔度实测 95.19→91.19 µm/N（约 4% 漂移），
   残差迭代负责吸收这部分误差。拓宽带宽后收敛反而更快（5 轮 → 2 轮）。
4. **模板是「单程拉长」的重复拼接**（前向 ×19、返向 ×14），稳态段假设统计平稳；
   缝跳跃均值 0.029 / 最大 0.035 µm。
5. `outputs/` 下的 `_mkzip.py` / `_verifyzip.py` 是交付打包与校验脚本，不属于仿真主干。

## 附：V1.1 批次结果（历史存档，口径为 `e_raw`，**非本轮结论**）

V1.1 跑了 39 组（标准三组 + 25 组 n×r 全扫描 + 12 组 K/B0 局部扩展），
0 组 INVALID / FAILED。要点：

* A0 25.767 / Alinear 18.662（+27.57%）/ 默认 ASFC 18.568（相对 Alinear 仅 **+0.50%**）；
* 第一轮最佳 n=1.5, r=4 → 17.459 µm（相对 Alinear +6.45%）；
* 单调性：`r` 增大有帮助，`n` 增大有害（n=4 时收益≈0 或为负）；
* 耗散检查全部干净：`P_shear_pos_frac = 0`，`E_shear ≤ 0`，`E_linear ≤ 0`，
  `clip_applied = False`，`frac_absF_gt_10N = 0`。

这些数字与 V1.2 不可直接比较，因为**问题口径变了**（V1.1 拟合的是含慢偏移的 `e_raw`）。
